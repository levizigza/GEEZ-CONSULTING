# Design foundation

CSS tokens and HTML primitives for the Blocksy child theme. **Not** a public site and **not** a Storybook app.

- Tokens: `tokens.json`, `css/tokens.css`
- Fonts: `css/fonts.css` (Noto Sans + Noto Sans Ethiopic, 400/700, `display=swap`)
- Primitives: `css/primitives.css`, `js/primitives.js`
- Fixtures: `lib/markup.mjs`
- Contrast helper: `lib/contrast.mjs`

See `docs/geez-redesign/design-system.md`.
