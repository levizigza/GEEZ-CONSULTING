# Client interview template — case studies

Use this script after engagement wrap-up. **Do not publish** until the [case-study approval checklist](./case-study-approval-checklist.md) is complete.

**Rules:** Never invent financing, revenue, profitability, or operational numbers. If the client only shares a feeling or a process story, record it as **qualitative**. Quantitative outcomes require metric definition, baseline, result, time window, and source.

---

## 1. Permission

| Field | Prompt | Capture |
|-------|--------|---------|
| Permission status | May we publish a story about this engagement? | `none` / `pending` / `story_anonymized` / `named_public` |
| Named identity | If named: exact legal or trading name to show | |
| Anonymized label | If anonymized: agreed label (e.g. “A Calgary-area driving school”) | |
| Quote permission | May we publish a quote? Exact wording approved? | Yes / No + final quote |
| Approver | Who approves the quote and story? Name + role | |
| Photo / logo | Permission for image? Rights confirmed? | Yes / No |

## 2. Client context

| Field | Prompt |
|-------|--------|
| Sector | What industry or trade best describes the business? |
| Business stage | Idea / pre-launch / early operating / growing / other (client’s words) |
| Situation | What was going on when they engaged Ge’ez? |
| Constraint | What limited them (time, language, capital access, systems, compliance)? |
| Goal | What did they want to achieve with Ge’ez? |

## 3. Work performed

| Field | Prompt |
|-------|--------|
| Work Ge’ez performed | What did Ge’ez actually do? (activities, not outcomes) |
| Deliverables | Tangible outputs (plans, books setup, checklists, coaching sessions, etc.) |
| Related service | Which core service fits? Start Strong / Plan & Funding Readiness / Books & Payroll / Grow with a System |
| Timeline | Optional — only if client confirms and we will approve the claim |

## 4. Outcomes

### Qualitative (default)

- Statement in the client’s or interviewer’s careful wording
- Leave metric fields **null**
- Do **not** turn quote phrases like “more profitable” into numbers

### Quantitative (only with evidence)

| Field | Required |
|-------|----------|
| Metric definition | What was measured? |
| Baseline | Value before / at start |
| Result value | Value after |
| Window | Time period |
| Source | Document, export, or client attestation ID |

**Forbidden without evidence:** loan amounts, approval guarantees, revenue, profit, margins, headcount, conversion rates, “% growth.”

## 5. Scope caveat

Confirm a caveat the client accepts, e.g. individual results vary; Ge’ez does not guarantee financing, legal, tax, or immigration outcomes.

## 6. CTA

Default public CTA: **Book a Fit Call** → `/book-a-fit-call/` unless a related service page is more appropriate **and** approved.
